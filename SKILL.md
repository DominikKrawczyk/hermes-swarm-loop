# Hermes Swarm Loop — 3 Phases × 3 Points × 11 Agents

## Phase 1: Foundation — 3 points
- Point 1: PRD BUILD — 66 agents (33 research + 33 build)
  Step 1: Ask user for PRD (questions)
  Step 2: 33 research agents
  Step 3: 33 build agents
  Step 4: Format PRD — ALL user input 1:1 quotations, no loss
- Point 2: ARCHITECTURE — 11 agents
- Point 3: SETUP — 11 agents

## Phase 2: Development — 3 points × 11 agents
- Point 1: AUDIT — 11 agents
- Point 2: IMPROVE — 11 agents
- Point 3: REVIEW — 11 agents

## Phase 3: Hunting — 3 points × 11 agents
- Point 1: BUGS — 11 agents
- Point 2: ARCHITECTURE — 11 agents
- Point 3: SECURITY — 11 agents

## Loop 3: Simplicity & Consolidation — 3 points × 11 agents
Runs after Phase 3. Feeds back to Phase 1.
- Point 1: Dead Code Consolidation — 11 agents (not destroy, consolidate, leverage scale, refactor audit, reposition architectural flaws)
- Point 2: Occam's Razor — 11 agents (testing/simulation bottlenecks reduction)
- Point 3: PRD Alignment → back to Phase 1 — 11 agents (Get To A visionary PRD reminiscence, audit HAP vs PRD, account for previous changes, alignment not further loops, PRD gap errors feed Phase 1)

## Cycle 1: BUILD — no iteration, no self-reflection
## Cycle 2+: ITERATE — self-reflection after cycle 3
## Rules
- Each point forced. No skipping. Gate at 11 agents per point.
- Scale: 11/33 → 999. No hard cap 400.
